# X Destiny — 설계도 v1.0

사주(四柱), 서양 점성술, 인도 베다 점성술, 중국 띠, 수비학, 토정비결을 **하나의 출생 정보**로 정확하게 계산해 풀어 주는 상담용 앱.
X Tarot과 같은 방식: 아이폰·갤럭시 PWA, GitHub Pages, 영어 기본 / 한국어 선택, 손님 관리.

## 1. 신뢰의 원칙
세계적으로 가장 신뢰받는 체계만 쓰고, 계산은 천문·역법 엔진으로 정확하게 한다.

| 체계 | 쓰는 곳 | 계산 기준 |
|---|---|---|
| 사주 (Four Pillars / BaZi) | 한국·중국·대만·동남아 | 절기(입춘·절입 시각)로 연·월주, 경도 보정 시각으로 일·시주 |
| 서양 점성술 (Natal chart) | 미국·유럽·전 세계 | 열대 황도대, 행성 실제 위치, 상승궁, 홀사인 하우스 |
| 베다 점성술 (Jyotish) | 인도·남아시아 | 항성 황도대(라히리 아야남샤), 달의 낙샤트라, 빔쇼타리 다샤 |
| 중국 띠 (Chinese zodiac) | 동아시아 전역 | 음력 설 기준 띠, 삼합·육합·충, 삼재 |
| 수비학 (Numerology) | 미국·유럽 | 피타고라스식 생명수(마스터 넘버 11·22·33), 개인 연·일 수 |
| 토정비결 | 한국 | 음력 생일 + 당해 태세수·월건수·일진수로 상·중·하괘 |

### 계산 엔진 (MIT 라이선스, 검증 완료)
- **lunar-javascript**: 양력↔음력, 24절기, 사주 팔자, 십신, 지장간, 12운성, 납음, 대운
- **astronomy-engine**: 태양·달·행성 위치(오차 1분 이내), 항성시
- 검증: 2000-01-01 정오 = 己卯·丙子·戊午·戊午, 1984 입춘 경계, 태양·달·금성 위치가 천문력과 일치

### 시간 처리
- 출생지 도시(시간대·위경도) → 역사적 서머타임까지 반영해 UTC로 변환
- 사주 연·월주: 절입 시각과 같은 기준(UTC+8)에서 판정
- 사주 일·시주: **경도 보정 지방평균시**(서울 약 −32분) — 설정에서 끌 수 있음
- 출생 시각을 모르면 시주·상승궁·하우스는 생략하고 나머지는 계산

## 2. 화면 (하단 탭 5개)
| 탭 | 내용 |
|---|---|
| **Today** | 오늘의 운세: 일진 십신 + 달 트랜싯 하우스 + 개인 일수 → 총운·연애·재물·일·건강 점수, 행운의 색·숫자·방향 |
| **Saju 사주** | 사주표(천간·지지·십신·지장간·12운성), 오행 분포, 일간 성격, 신강·신약, 간이 용신, 신살(도화·역마·화개·천을귀인), 대운 흐름(현재 강조), 세운 |
| **Stars** | 서양 출생 차트(원형 차트 그림), 태양·달·상승궁, 10행성 별자리·하우스, 주요 각, 원소·모드 균형 / 베다: 달 라시, 낙샤트라·파다, 현재 마하다샤·안타르다샤 |
| **Year** | 올해 세운, 월별 운(12개월 월주 십신), 토정비결, 띠 운(충·삼재·궁합), 개인 연수, 목성·토성 트랜싯 |
| **People** | 프로필(나·손님) 관리, 궁합(두 사람), 설정(언어·경도 보정), 백업 |

## 3. 해석 데이터 (영어·한국어 각각 원문 작성)
일간 10 · 십신 10(성격·오늘·올해) · 오행 5(과다·부족·행운) · 신강/신약 · 신살 4 · 별자리 12(태양·달·상승) · 행성 10 · 하우스 12 · 각 5 · 달 하우스 오늘 운 12 · 낙샤트라 27 · 다샤 9 · 띠 12 · 수비학 12 + 개인 연 9 · 토정 괘 8+6+3

## 4. 궁합
사주 일간 합·충, 띠 삼합·육합·충, 오행 보완, 태양·달 원소 조화, 생명수 조화 → 점수와 풀이

## 5. 부가 기능
리포트 공유(카톡·문자), AI 심층 해석용 복사, 프로필 백업, 오프라인 동작, 큰 글씨
